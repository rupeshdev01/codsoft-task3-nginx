# CODSOFT Task 3: Nginx Web Server

## Objective
Install and run Nginx web server on Ubuntu using WSL.

## Work Completed
- Installed Nginx.
- Started the Nginx service.
- Created a custom HTML webpage.
- Verified the webpage using http://localhost.
- Tested Nginx configuration using nginx -t.
- Verified the HTTP response using curl.

## Result

The Nginx web server is running successfully and serving a custom HTML page.
